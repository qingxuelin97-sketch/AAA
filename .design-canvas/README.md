# 设计画布源文件

「幻域 App 改版」设计画布的**源文件**。每个 `*.dc.html` 是画布上的一块画板，
`canvas.json` 是版面清单（两页十块），`_tokens.css` 是画板共用的令牌样式。

## 与仓库代码的关系

画板里的色值、字号、圆角、间距**全部取自仓内真源**，不是另立一套：

| 画板取的值 | 真源 |
|---|---|
| wash / ink 十四支、`--ix-act` / `--ix-ink*` / 基面色 | `client/src/styles/app-rainbow.css` §0 与 §9 |
| 字号阶梯、间距阶梯、时长与缓动令牌 | `client/src/styles/app-ix-tokens.css` |
| 字体栈 | `client/src/styles/base.css:33` |

改仓内令牌时，这里的 `_tokens.css` 要跟着改，否则画布会开始说谎。

## 两页各是什么

* **屏 · 改后全貌**（六块）—— 今日 / 发现 / 消息 / 设置 / 我的 / 钱包。
  芯片已是撤形后的形态（淡染面 + 深墨字形 + 内描边环），对应已落地的提交 `b65fecd`。
* **规范 · 四张** —— 空·载·错三态、页面壳与骨架、动效与材质预算、文案口径。
  这四张是七张设计卡里**还没落地**的部分，转成了可施工的规格。

## 重新生成

产物 `huanyu-app-redesign.html` 内含画布编辑器（约 2.5MB），**不入库**，
用 `/design` 技能的 `seed-canvas.mjs` 从上面这些源文件重新生成即可。
