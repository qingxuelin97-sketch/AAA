# 幻域 · 「仪与匣」The Field Instrument — App 全局设计规范 v1.0

状态：`v1.0 / 设计权威 / 仅 App 壳（html[data-app="1"]）`
替代对象：`曜光玻璃 Lumen Glass v1.0` 的视觉层。产品结构、路由注册、状态矩阵、Web 零差异边界全部继承，不重复推翻。
令牌：`design-tokens.css`（--ix-*，冻结件，逐字节实现）。
视觉稿：`mockup.dc.html`（22 帧）· 色板：`tokens-色板校样.dc.html` · 插画：`插画风格板.dc.html`。

## 0. 一句话定义

App 是一台随身的观测仪器：铝白/石墨实体面板承载一切内容，数据以等宽「读数」呈现，发光只属于毫米级 LED，每日仪式是一次拨杆与翻牌。冷的是外壳，暖的永远是人——头像与立绘是系统里唯一的暖色开窗。

## 1. 层级与材质规则表

| 层 | 材质 | 令牌 | 用途 | 铁律 |
|---|---|---|---|---|
| 页面底 | 铝白/石墨实体 | --ix-canvas | 全部页面最底层 | 零渐变；分区靠 1px 刻线与 8px 沟槽（--ix-grouped），不靠色块 |
| 内容面 | 仪表面板实体 | --ix-surface + --ix-shadow-1 | 卡、列表组、气泡、表单 | 不透明；正文永远在面板上；卡不叠卡 |
| 浮起面 | 实体 | --ix-raise + --ix-shadow-2 | 菜单、弹层的不透明基底 | lite 档玻璃的回落目标 |
| 导航/临时层 | 玻璃 | --ix-glass-nav / --ix-glass-temp + --ix-blur | Dock 滚动态、顶栏、Sheet、输入岛、长按菜单、浮层 | 全系统唯一 blur 许可；永不承载正文段落 |
| 表盖 | 静态高光 | --ix-glare | 数据表盘（星轨/钱包/周报/分享卡） | 45° 一道，永不移动、永不动画 |
| 金融舱 | 独立深实体 | --ix-vault-* | 钱包/充值/VIP 仪表、星轨 hero、分享卡 | 深浅共用；舱内 CTA 固定亮青 #3FD2B4、金读数 #E0A83E |
| LED | 发光点 | --ix-led / --ix-led-halo | 未读、在线、录制、选中键 | 4–8px，光晕一圈 ≤3px；发光的唯一许可 |
| 键帽 | 实体按键 | --ix-shadow-key-down / --ix-key-travel | 按钮、Dock 键、开关 | 按下=下沉 1px，非缩放 |

媒体沉浸页（发现瀑布/对话立绘/通话）：媒体即第一层，文字一律压在底部渐隐遮罩（黑 0→82%）上，对比 ≥4.5:1——这是全系统唯一允许的媒体遮罩渐变。

## 2. 色彩

- 中性双面板 + 单一主强调：磷光青 --ix-act（浅 #0E7263 / 深 #3FD2B4），用于指针、选中、主按钮、焦点环。
- 语义色相冻结、仅明度补偿，永不随主题或用户强调色漂移：危险 #B03427/#F2705C · 成功 #2E7C3F/#7BD08D · 奖励金/警示 #8A600A/#E0A83E · 钻 #33639B/#8FBCE8 · 未读角标单值 #D6452C（数字 ≥11px/700/tabular）。
- 允许的渐变仅三类：媒体可读性遮罩、奖章/印章金属本体（radial）、表盖高光。禁止 nth-child 彩虹、渐变文字、无语义渐变底。
- 图表单色相：当前值实心 act，历史值同色 30% 透明度。
- --ix-ink-3 只用于 ≤13px 辅助与禁用态。

## 3. 排版与几何

- UI：system-ui/PingFang SC/HarmonyOS Sans；一切读数、时间戳、单位、编号 = 等宽 --ix-font-mono；中文永不套等宽，读数与中文间距固定 4px；金额 tabular-nums。
- 字阶：34 大标题（700/-1%）· 22 页面 · 17 分区 · 15 正文（行高 1.7）· 13 元数据 · 11 铭牌（mono/+12% 字距）· 读数 28 / 40（mono 600，行高 1.15）。
- 圆角机加工五档：4 微章 / 6 控件键帽 / 10 卡开窗 / 14 面板机身 Sheet / 999 表盘胶囊。不随层级放大。
- 间距 8 点网格：8/16/24/32（辅 4/12）；页边 16；触控 ≥44；提交 ≥48；Dock 64 + safe-area；头像/媒体开窗描边 2px。
- 刻度即进度：进度一律以刻线带呈现（--ix-tick 2px，短刻 8，里程碑刻 14，间距 4），每根刻线必须绑定真实数据点。
- 基准 390×844；360×800 与 412×915 必须成立；横向溢出 ≤1px。
- 图标沿用 lucide-react：22px / stroke 1.75 / 圆头；Dock 24px；图标按钮必须有可访问名称。

## 4. 组件契约（对照 ui-kit）

- 按钮：primary=act 实底（键帽高光 inset 0 1px 0 白 25–35%）/ secondary=surface 键帽 / tertiary=act 纯文字 / danger=danger 描边、确认后实底。pressed=下沉 1px + --ix-shadow-key-down，80ms；loading=原位 spinner 保持原宽 + aria-busy；disabled=55% 透明 + 写明原因，不进 Tab 序。
- 分段控件：grouped 胶囊槽 + surface 选中片（shadow-1），滑移 180ms。
- 开关=拨杆：120ms 到位零回弹，开启后杆帽旁 LED 点亮。
- 输入框：面板上开 inset 窗（--ix-shadow-dial），focus = --ix-focus-ring 双圈。
- Dock：机身实体条（滚动时转玻璃 --ix-glass-nav）；四目的地 + 中央凸起创建键（54px act 圆）；选中 = act 色 + 键上方常亮 LED + aria-current="page"；未读 = badge 胶囊。详情/会话/编辑页隐藏 Dock。
- 列表行：设置 56 / 会话 72；发丝分隔 --ix-hairline；未读三重编码（LED 点 + badge 数字 + 标题加粗）；左滑动作跟手（静音 grouped / 删除 danger）。
- Sheet：--ix-glass-temp + blur，顶角 14，grabber 36×4；从底部 300ms 升起；Portal 到 body，role=dialog，焦点锁、scrim --ix-scrim、Escape/返回关闭、焦点归还；危险确认默认焦点在取消。
- 长按菜单：glass-temp 浮层 + 键帽行 44h；触感一次。
- Toast：raise 实体 + 语义 LED 点，进出 180ms 上滑，一次。
- 日历格四态：已签=act 实心（r8，ink 反白）/ 今日=1.5px act 描环 / 缺签=grouped+ink-3 / 未来=纯 ink-3。
- 奖章三档：金 #F6DFA0→#D9A93F→#A67818 / 银 #F3F6F8→#C4CDD3→#8D989F / 铜 #EBC09A→#C68B57→#8F5B2E（radial，仅限奖章本体）。
- 印章三档：铜单环无芒 / 银双环短芒 / 金三环长芒 + 外放射（见插画风格板）；牌面零文字，数字活文本叠加。

## 5. 动效（机械确定性，一次即止）

缓动仅两条：--ix-ease（快进慢停）/ --ix-ease-stop（指针到位）。
按压 80 · 拨杆 120 · 状态 180 · 推入 220 · 翻牌 130+130（错峰 40）· Sheet 300 · 指针 540（仅首次）。
骨架 shimmer 与 loading 旋转是仅有的循环，状态结束即停；lite 档骨架静态。
reduced-motion：全部时长归零，翻牌/指针直达终值，触感保留。
禁止：无限循环装饰、扫光、呼吸灯、粒子、按列表位置配色、渐变文字。

## 7. 无障碍承诺

- 对比度：正文 ≥4.5:1、大字/图形 ≥3:1（色板校样已标实测）；ink-3 永不作正文。
- 焦点：--ix-focus-ring 双圈全组件可见；Sheet/菜单焦点锁与归还；危险确认默认焦点=取消。
- 触控 ≥44；未读/状态三重编码（色+形+文），不单靠颜色。
- reduced-motion 与 lite 全覆盖；LED 信息必伴文字或角标。
- 金额/读数 tabular-nums，屏幕阅读器读完整单位。
