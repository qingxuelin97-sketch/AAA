风格名：「工作台上的小仪器」

每一张插画都是一台被放在台面上的小器械，讲一件事：空态 = 仪器就绪、等待第一个读数；引导 = 器械的「首次校准」；印章 = 铸出来的纪念圆牌。纯几何件（圆 / 环 / 线 / 点）拼装，可直接矢量化交付。

调色板（tokens） 石墨线 #2E3532 铝线(深底) #C9D2CE 面板 #F6F8F7 磷光青 #3FD2B4 琥珀 #E0A83E 赭金 #8A600A 暖驼(人味) #D9CDBB
几何 · 120 网格 / 8 点对齐；只用圆、环、直线、点；主体高 ≤72%，四周留白 ≥14%；构图居中，重心略低。
描边 · 主线 2.5 / 辅线 1.5，圆头；虚线只表「轨道与待完成」；LED 光晕最多一圈、透明度 ≤20%。
用色纪律 · 单张 ≤3 色 + 描边；青 = 生机/就绪，琥珀 = 奖励，暖驼 = 唯一的人情味；透明底，浅深各出一版线色（石墨 / 铝）。
样张 01 · 空态「还没有对话」
EMPTY / CHAT
叙事：表盘已通电，指针指向远处一颗亮起的星——第一句话就在那里。构成：虚线轨道 ×1、表盘 ×1、指针 ×1、星 LED ×1、支脚 ×2。
同一资产两版线色：浅底石墨线 / 深底铝线；青色在浅底降为深青 #0E7263 守对比。指针永远指向「下一步会发生事情的方向」——空态插画的统一叙事机关。
样张 02 · 引导主视觉「月门」
ONBOARDING / 001
叙事：一枚暖色的月嵌在校准环中，台阶引向门内——整套体系里唯一的大面积暖色。构成：虚线外环、实线门环、暖月、顶部 LED、轨道金点、台阶 ×3。
引导三屏共用此语法：001 月门（世界观）、002 三台小仪器并置（玩法）、003 罗盘环上多枚待选圆点（兴趣校准）。暖驼月 = 「人」的位置，与 App 内头像开窗同源。
样张 03 · 连签纪念印章「100 天 · 金」
STAMP / GOLD
叙事：滚花边金牌，中心一颗星芒。三档梯度只靠工艺复杂度递进：基础铜 = 单环无芒；30 天银 = 双环短芒；100 天金 = 三环长芒 + 外放射。数字由 UI 活文本叠加，牌面本身零文字。
金牌为深浅单资产（金属自带对比），深底仅外放射与滚花提亮为琥珀。银章 = #C4CDD3/#8D989F，铜章 = #C68B57/#8F5B2E，结构同源递减。
