## 关于本包内文件

本包内全部 `.dc.html` 均为 **HTML 设计参考稿**（原型，展示目标外观与行为），不是可直接搬运的生产代码。任务是：在目标代码库现有环境（React 组件 + CSS 变量）中**逐屏重建**这些设计。唯一例外：`design-tokens.css` 是**可直接落地的冻结件**，逐字节放入 `client/src/styles/`，作用域包在 `html[data-app="1"]` 内（同 lumen-glass-tokens.css 的接法）。

## 核心世界观（一句话）

铝白/石墨双面板 + 等宽「读数」+ 毫米级 LED + 机加工几何；签到 = 拨杆翻牌，一切动效是机械应答。

## 硬约束（实现时逐条对照）

1. 基准 390×844，必须在 360×800 / 412×915 成立；触控 ≥44×44，提交按钮高 ≥48（`--ix-hit-min` / `--ix-hit-submit`）。
2. 浅深为等价主题（非滤镜）：只切 `data-theme="dark"`，组件不得写死颜色。
3. lite 档 `data-perf="lite"`：blur/表盖高光/拉丝/LED 光晕全部归零，玻璃回落不透明——已在 tokens 内实现，组件只引用变量即可免费获得。
4. 语义色相冻结：危险红 / 成功绿 / 奖励金 `--ix-gold` / 钻蓝 `--ix-dia` 永不随主题或用户强调色漂移；未读角标 `--ix-badge:#D6452C` 深浅单值。
5. 玻璃（`--ix-glass-*` + `--ix-blur`）只许出现在：Dock/机身条滚动态、顶栏、Sheet、输入岛、长按菜单、浮层，以及数据表盘的「表盖」静态高光 `--ix-glare`。内容面一律 `--ix-surface` 不透明。
6. 金融面（钱包/充值/VIP）用 `--ix-vault-*` 独立实体，深浅共用；舱内 CTA 用固定亮青 #3FD2B4、金读数 #E0A83E。
7. 动效必须有因果、一次播完；时长/缓动只取 `--ix-dur-*` / `--ix-ease*`；禁循环、扫光、呼吸、按位置彩虹、渐变文字。
8. 圆角只有 4/6/10/14/999 五档（`--ix-r-*`），不随层级放大。
9. 插画/印章素材零文字零按钮，数字由 UI 活文本叠加。
10. `--ix-ink-3` 只用于 ≤13px 辅助信息与禁用态。

## 关键动效清单（触发 → 表现 → 时长 → 降级）

- 翻牌（连签/金额变化）→ split-flap 上下半页各 130ms，多位数错峰 40ms → `--ix-dur-flip` → reduced-motion 直接替换数字
- 拨杆（签到/开关）→ 120ms 到位零回弹 + LED 点亮 + 触感 → `--ix-dur-flick` → 直切，触感保留
- 指针（星轨/周报仪表首次入场）→ 0→读数 540ms 过冲 2° 回正，仅一次 → `--ix-dur-needle` → 直达
- 键帽按压 → 下沉 1px（`--ix-key-travel` + `--ix-shadow-key-down`）80ms
- Sheet → 底部升起 300ms `--ix-ease-stop`；页面推入 220ms `--ix-ease`
- 骨架：`--ix-skeleton` 单向 shimmer，数据到达即停；lite 档静态

## 逐屏要点（对照 mockup 帧内标签）

- **今日**（长屏，Dock 常驻）：问候+34px 大标题+mono 日期行；金融舱卡（GOLD/DIAMOND 读数 + 签到主按钮 44h + 7 粒连签点 + 月历入口）；2×3 键帽宫格 72h；精选卡=开窗 150h+铭牌+CTA；续读横轨（刻度进度）；任务清单（行内 领取/前往 28h 按钮）；周报卡（7 柱 + mono 统计 + 最相伴行）。
- **发现**：双列沉浸瀑布，图上文字压底部渐隐遮罩（唯一允许的媒体遮罩），徽标：剧场LIVE=#D6452C、NEW=act、免费=success；Dock 玻璃滚动态。
- **对话**：身份栏（头像 ring `--ix-window-ring` + 在线 LED + mono 状态行）；角色气泡=surface 面板（左下角 4px），动作文=斜体 ink-3；用户气泡=act 实底；建议芯片=act-soft；输入岛=玻璃 `--ix-glass-nav`+blur，内嵌 inset 输入位（`--ix-shadow-dial`）+ act 发送键 40。
- **消息**：34px 标题 + 聊过/赞过分段；入口行（互动/私信/群聊，32 图标位 + 语义 soft 底）；会话行 72h：置顶=「顶」act 微章、免打扰=斜杠圆、草稿=`[草稿]` danger 色、未读=badge 胶囊。
- **成就殿堂**：68% 主环（conic）+ 五分类小环 + 金银铜三档金属圆牌（radial-gradient 仅限奖章本体）+ 48h 金色一键领取 + 列表行 64h。

- **星轨**：vault 深舱 hero（轨道环 + 行星点 + 头像窗 + 第 N 天读数）；14 柱状（今日实心，历史 30% 透明度——同一色相，非彩虹）；羁绊 Top5 条形；创作 2×2 读数宫格；经济三胶囊。
