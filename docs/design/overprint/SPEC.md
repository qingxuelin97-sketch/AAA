# 幻域 ·「叠印」Overprint — 设计规格 v1.0

> 权威级别：App 壳**一级四页与机身条**的视觉与交互权威。
> 产品结构、路由注册、状态矩阵、无障碍承诺与 Web 零差异边界继续由
> `APP_UI_ORACLE.md` 管辖，本稿不改写其中任何一条。
> 实现契约以 `client/app-test.mjs` 与 `server/quiet-aqua-e2e.mjs` 的机器断言为准。

## 1. 为什么有这一代

「仪与匣」IX 解决的是**材质与秩序**——铝白/石墨双面板、等宽读数、机加工几何。它做得很好，但落到一级四页时完成度并不均衡：承载一级四页的 `app-ix-pages-a.css` 只有 284 行，其中今日占了六成、消息两成，**发现只有 4 条规则、我的只有 2 条**。IX 自己的 `field-instrument/SPEC.md` §6 也把「我的」标注为「ui-kit 后补帧」。真正的布局结构仍沉淀在下方上万行历史层里。

叠印解决的是**一级页面的信息密度与浏览节奏**。它回答三个 IX 没有回答的问题：


1. **沉浸流怎么和机身条共处。** IX 的发现页是纯全幅，媒体铺到 Dock 底下，靠玻璃透出来。叠印把每屏做成一张圆角卡 + 底部留白，机身条永远压不到内容，翻页也从「滚动」变成「一页一张」的确定动作。
2. **列表的右边缘归谁。** IX 的会话行把时间戳右对齐、再塞进「⋯」菜单键，右边缘被两件事瓜分，未读状态没有稳定位置。叠印把时间戳内联到预览文字之后，右边缘整块让给**未读胶囊 / 箭头 / 行内 CTA 三者互斥**的单一插槽。
3. **中性灰从哪来。** IX 有三档文字墨 + 散落各处的一次性 rgba。叠印规定**一种墨、七档密度**，文字、分隔线、胶囊底、按下态全部由同一个通道值派生。

## 2. 世界观

**一种墨，七档密度。零投影。媒体先于文字。**


纸面上只有一种墨，靠密度分层次；深度来自遮罩，不来自阴影；界面是压在媒体上的一层印痕，而不是浮在媒体上的一叠玻璃。

## 3. 与 IX 的边界

叠印**扩展**而非替换 IX。它补的是 IX 缺失的四件事：墨阶、零投影、媒体遮罩、表面极性。

> 曾经还列过第五件「描边胶囊作为标志控件」。落地时发现它在这四个页面里没有归属
> —— 参考素材的描边控件是白底页上的搜索输入框，而幻域 App 的搜索在沉浸媒体上
> 是个图标按钮。与其硬塞一处，不如撤掉这条：**规格不该描述产品里不存在的东西。**

| 归 IX | 归叠印 |
|---|---|
| 圆角五档 4/6/10/14/999 | 墨阶七档 |
| 间距六档 4/8/12/16/24/32 | 零投影纪律与 `--ov-ring` |
| 触控 ≥44 / 提交 ≥48 | 媒体遮罩 |
| 全部语义色相（危险红 / 成功绿 / 奖励金 / 钻蓝 / 未读角标） | 表面极性 `data-surface` |
| 强调色 `--ix-act` 与 accent 机制 | 一级四页与 Dock 的度量 |
| 全部动效时长与缓动 | — |
| 金融舱 `--ix-vault-*` | — |
| 玻璃 `--ix-glass-*` 与 `--ix-blur` | — |
| **约 40 条二级与深层路由的全部视觉** | **一级四页 + 机身条** |

`design-tokens.css` 里不重定义任何 IX 已有的令牌，一律 `var(--ix-*)` 继承。这是刻意的：从发现页点进角色详情会跨越材质接缝，让接缝只落在材质层而不落在几何层，跨页才不割裂。

## 4. 墨阶

浅色墨取 `#181D1B` 的通道值（与 IX 发丝线同源），深色墨取 `#ECF1EF`，沉浸台恒为纯白。

| 档 | 角色 | 浅底对比度 |
|---|---|---|
| `--ov-ink-100` | 正文与标题 | 16.0:1 |
| `--ov-ink-70` | 次级正文 | 6.1:1 |
| `--ov-ink-55` | ≤13px 元数据与禁用 | 3.8:1 |
| `--ov-ink-22` | 强分隔线 / 禁用图形 | 不排字 |
| `--ov-ink-13` | 发丝线 / 控件按下底 | 不排字 |
| `--ov-ink-05` | 胶囊静止底 / 行按下 | 不排字 |
| `--ov-ink-03` | 最轻底纹 | 不排字 |

**只有前三档承载文字。** 22 及以下是填充与线，永不排字——这不是风格偏好，是把「看起来像字但读不了」的档位从系统里物理删除。

> 第三档定为 55% 而非参考素材里的 45%。45% 在 `--ix-surface` 上实测 2.83:1，连 3:1 的图形阈都过不了；55% 是 3.8:1，能安全承载 ≤13px 辅助信息。这是一处刻意的无障碍修正，不要「还原」回去。

## 5. 零投影

内容面的边界由 `--ov-ring`（1px 内描边）或填充档差表达。**全系统唯一允许的投影是 `--ov-shadow-float`，且仅用于浮层徽标**（压在媒体上的类型章、置顶章）。

这条替换掉 IX 在一级页面上的 `--ix-shadow-1`。深页仍归 IX，仍有 `--ix-shadow-1`——这是已知且接受的接缝。

## 6. 表面极性

极性**由路由声明，不由主题决定**。`routeRegistry.js` 为每条一级路由声明 `surface`，`AppLayout` 写到 `.app-root[data-surface]`：

- `immersive`（发现）：恒为深台 `--ov-stage`，与 `data-theme` 无关。墨阶翻转为纯白。
- `index`（今日 / 消息 / 我的）：跟随主题。

机身条与页面共读同一个属性，图标以 **100% / 40% 两档透明度**表达激活态，不再用滑动药丸和强调色。这是参考素材里「每个 tab 图标都出深浅两套」的真正原因——底不同，图标就得换极性。

## 7. 逐屏实施要点

| 屏 | 路由 | 要点 |
|---|---|---|
| 今日 | `/today` | 金融舱卡**原样保留**（IX-3 契约）；区块头收到 48、标题 17 粗体、尾部动作退三阶墨；横轨卡 2:3 满幅封面 + 60px 遮罩 + 13 粗体名 + 11 等宽计数。**首屏高度不得增加**（e2e 几何闸：故事卡 CTA 必须完整浮出 Dock） |
| 发现 | `/` | 一屏一张圆角卡 + 8px 底部留白，贴合翻页；顶部分段可滚动、选中自动居中、28×2 下划线；右侧动作轨 50 列宽、32 图标 + 11 等宽计数；双击点赞首启引导；长按 → 查看角色 / 分享 / 不感兴趣 |
| 消息 | `/messages` | 会话行 80 / 头像 56 圆角方形；**时间戳内联在预览之后**，右边缘整块让给操作；子分段下划线与发现页同几何 |
| 我的 | `/me` | 88 头像 + 24 粗体名 + 三统计（圆角竖条分隔）+ **两枚等宽 44 主键**；统一金刚区宫格（28 图标压 13 标签）；48 区块头带尾部胶囊；内容瓦片满幅封面 + 140 遮罩 |
| 机身条 | — | 四目的地 + nav 外创建键的**结构不变**；创建键从圆形 FAB 改为 56×32 加宽内联键位；图标 100%/40% 二档；未读角标加 1.5px 同色描边环；双击当前 tab = 刷新 |

## 8. 不做的事

- 不引入参考素材的品牌色、logo、插画或图标本体
- 不改圆角阶（继续 4/6/10/14/999）——参考素材的 12/16/20/24 会和仍在 IX 上的深页割裂
- 不改语义色相，不改强调色机制
- 不动金融舱、不动货币图标本体（用户特批 2026-07-26 起持续有效）
- 不引入任何循环动效；动效仍须有因果、一次播完
- 不碰 Web 壳。每条选择器从 `html[data-app="1"]` 起始，`web-lumen-*` 与 `--lg-*` 体系零波及

## 9. 验收

```
npm run test:app        # 静态契约，含 --ov-* 孪生逐字节断言与围栏断言
npm run test:web        # 证明 Web 壳零波及 —— 本代最关键的一道
npm run test:app:e2e    # 六组合矩阵 + 全局质量闸
npm run smoke
npm run test:server:s7
```

全局质量闸（`pageQualityAssertions`，每屏都跑）：零横向溢出 ≤1px、每个可见控件 ≥43.5×43.5、每个图标按钮有非空 `aria-label`、零控制台错误。

改动前的 IX 基线存于 `docs/ui-baselines/manual-v10-ix-before/`（81 张，五组视口）。改动后重录同名目录 `manual-v10/` 并排比对。

> `scripts/appdiff.mjs` 是 0 像素差重构闸。叠印是**有意改版**，应当重录基线，不要拿它判回归。
