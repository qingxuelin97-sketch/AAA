# Pink v1 App references

The four files in `source/` are the user-provided visual oracles for the App-only
light theme. Run `node scripts/bake-pink-v1.mjs` to normalize them to the canonical
390 x 844 viewport and split each screen into runtime PNG regions.

The bake also emits 42 standalone PNG glyph crops (search, notification,
interaction, feature-entry and Dock icons) under `client/public/app-pink-v1/icons/`.
`client/public/app-pink-v1/baked/manifest.json` records source, baseline, generated
art, partition and icon SHA-256 values. Every runtime PNG is normalized to RGBA.

ImageGen is used for clean, dynamic-user artwork plates. The runtime demo may
bake fixed copy into PNG regions; all controls remain real semantic DOM hit areas.

## Built-in ImageGen prompts

- `today-luchen-art.png`: precise-object-edit of the Today reference. Preserve the
  male character, pose, room, framing and warm morning light; remove all UI and
  reconstruct hidden scene pixels.
- `discover-linwan-art.png`: precise-object-edit of the Discover reference. Preserve
  the woman, rainy station and framing; remove all App chrome while retaining the
  environmental safety sign.
- `messages-watercolor-header.png`: reconstruct the cream watercolor window,
  leaves, curtain and floral light from the Messages reference with no UI or text.
- `profile-xiaoyu-avatar.png`: identity-preserve portrait derived from the Profile
  avatar; retain brown eyes, dark wavy hair, pink ribbon, flowers and blush outfit.

All four images were produced with the built-in ImageGen tool. No CLI fallback or
model-native transparency was used.

## Reviewed verification

The `implementation/` and `diff/` folders are generated by
`npm run test:app:pink`. At the canonical viewport, all four full-screen captures
match their normalized source with a 0.000% pixel difference (2% is the failure
threshold). The suite also checks 360 x 800 and 412 x 915 anchors, 44px touch
targets, horizontal overflow, dark-theme fallback, PNG signatures/alpha-capable
color type and the absence of SVG nodes/resources in the new light views.
